[Short description of the addon.]

## Compatibility

- Ember.js v4.12 or above
- Embroider or ember-auto-import v2

## Installation

```
ember install @lan0/ember-power-time-picker
```

This addon is built on top of [ember-power-select](https://github.com/ember-power-addons/ember-power-select) and for that reason you need to ensure that your app already has the `basic-dropdown-wormhole`. The simplest way to do that is to add this element to your `application.hbs`.

```hbs
// application.hbs

{{outlet}}
<div id='ember-basic-dropdown-wormhole'></div>
```
